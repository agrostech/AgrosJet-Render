**Key Technical Concepts**
-   **Event-Driven Architecture:** Shifted the violation system from an inefficient polling model (checking all users every X minutes) to an event-driven model. -   **Dynamic Job Scheduling (APScheduler):** Implemented a sophisticated scheduling system where jobs are dynamically created, updated, and deleted in response to CRUD operations on shifts. The scheduler state is persisted by re-populating jobs from the database on server startup.
-   **Timezone-Aware Logic:** Corrected backend logic to use the application's local timezone ('Europe/Istanbul') for all shift-related time comparisons, ensuring accuracy.
-   **Complex Business Logic:** Handled tricky edge cases in the violation logic, such as couriers with back-to-back shifts, to ensure logs are accurate and fair.
