-   **External API Integration:** Built a complete feature around a third-party API, including  authentication, data fetching, and status updates.
-   **Backend as a Proxy (BFF):** Used the backend to proxy requests to the external API, abstracting the frontend from the third-party service and securely managing API keys.
-   **Dynamic UI Rendering:** The UI (filter buttons, status dropdowns, badges) is generated dynamically from data fetched from API endpoints, making it resilient to changes in the external system.
-   **Role-Based Access Control (RBAC):** The new page is only accessible if the admin user has the  permission.
-   **Configurable Settings:** The integration's API URL and key are managed through a dedicated settings UI, allowing for easy updates without code changes.
-   **Cache Busting:** Implemented a  parameter to ensure fresh data is fetched on every page load and tab switch.
