-   **Conditional UI and State Management:** The frontend now handles complex conditional logic for both admins (settings) and couriers (queue status, dynamic buttons), managed with React hooks.
-   **Push Notifications (FCM):** The system uses Firebase Cloud Messaging to send real-time alerts to the courier's mobile application.
