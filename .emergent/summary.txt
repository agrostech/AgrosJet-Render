    *   The single list of active orders should be replaced with two tabs: Atanmış (Assigned) and Yoldaki (On the way).
    *   Order cards should be visually distinct using shadows and colored side-borders (purple for assigned, blue for on the way).
    *   UI elements on the courier dashboard should be reorganized for a cleaner look (e.g., move notification button to header, move break time info into the status dropdown).
5.  **Order Age Display:**
    *   The age of an order (time since creation) must be displayed on both the courier and admin order cards.
    *   The format should be in total minutes (e.g., 77 dk).
    *   On the admin panel's mobile view, the order age should be displayed in red if it exceeds 35 minutes.
